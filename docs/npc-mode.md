# NPC / 客服模式：让她有问必答

自主模式（v2）默认「沉默是合理的」。但有些场景需要**确定性**：
剧本杀 NPC、客服、陪聊、角色扮演互动装置——玩家发一句话，必须有回应。

这类场景用 **v1 应答模式**。

---

## 1. 三条命令

```bash
python run_wx.py                   # v1：门控 / 应答模式
python run_wx.py --v2              # v2：自主模式（默认不用于 NPC）
```

v1 的两种形态由 `thresholds.always_reply` 决定：

| `always_reply` | 群里没人叫她时 | 私聊 / 被点名时 |
|---|---|---|
| `false`（默认） | 按概率门决定（可能不说话） | 几乎必回（只防刷屏） |
| `true` | **每条都回** | 每条都回 |

私聊/被点名时 v1 本来就是「直接回」，`always_reply` 补的是**群聊**这一块。

---

## 2. 配置

`config.json` → `thresholds`：

```json
{
  "always_reply": true,
  "recall_limit": 12,
  "facts_per_person": 15,
  "events_per_person": 6,
  "min_think_gap": 20,
  "quiet_hours": []
}
```

| 键 | 作用 | NPC 建议 |
|---|---|---|
| `always_reply` | 群聊也每条都回 | `true` |
| `recall_limit` | 每轮从库里捞几条旧事 | 8～20，看场景长度 |
| `facts_per_person` | 每个在场的人带几条事实 | 15～40（角色设定多就调高） |
| `events_per_person` | 每个在场的人带几条最近事件 | 6～12 |
| `quiet_hours` | 这个时段不主动开口 | NPC 场景常设 `[]`（随时在线） |
| `speak_gap` | 说完话多久能再说 | `0`；怕刷屏就设 1～3 秒 |

**成本提醒**：v1 是「每条消息 1 次 LLM」，调大 `recall_limit / facts_per_person`
就是直接加 prompt 长度。一个 20 人的群 + facts 40 + events 12，单次 prompt
可能到 4～6k token。先在面板上看一眼实际长度再上线。

---

## 3. 「长期全量记忆」怎么理解

v1 不是把所有历史塞进 prompt，而是：

```
每轮注入 = 最近 16 条对话
         + 在场每个人的 N 条事实（身份/经历/偏好/关系）
         + 在场每个人的 M 条最近事件
         + 按当前这句话召回 12 条旧事
```

所以「全量」指的是**全量存**、按需带，而不是全量塞。
真要「这个角色必须记得剧本里的每一句」，正确做法是把剧本写进**人设卡**
（`记忆/人设卡.md` 的 L1 内核），而不是指望检索：

- 人设卡每一轮都会进 prompt（`core/persona.py: load_persona`）
- 剧本设定、世界观、不可违背的规则，都写在这里
- 事实与经历交给数据库，让它随对话长出来

## 4. 剧本杀 NPC 的推荐做法

1. **一个角色一个 profile**。`config.json` 的 `profiles` 下每个角色独立库、独立记忆目录。
   两个 NPC 可以同时在线（各自一个 `--profile`，端口按序号错开）。
2. **人设卡写死「不能做的事」**。NPC 最怕出戏和乱承诺：
   - 不要说自己是 AI / 模型 / 程序
   - 不透露剧情真相，哪怕被直接问
   - 不答应剧情外的请求（加微信、线下见面…）
   - 不确定就演「不知道」，不要编设定
3. **把「她」变成「他/它」**。`记忆/我是谁.md` 与 `人设卡.md` 都用第一人称写，
   名字改了要同步 `config.json` 的 `identity.names`（用于判断「是不是在叫她」）。
4. **关掉自主行为**。NPC 不需要半夜自己发消息：
   `switches.auto_sleep=false`、`switches.share=false`、`switches.browse_bili=false`。
5. **限速**。一个玩家群里 5 个人同时说话，`always_reply` 会让它连回 5 条。
   用 `speak_gap` + v1 自带的「10 分钟上限」兜底；更稳的做法是一个场景一个人格实例。

---

## 5. 和自主模式混用

同一套库、同一份记忆，两种模式可以切换着跑（但**不能同时跑**）：

- 白天接待玩家：`--always_reply` / v1
- 夜里自己长：停掉 v1，用 `--v2` 跑一段，让它整理记忆、写日记
- 第二天再切回 v1 —— 它在 v2 期间抽出来的事实、关系、日记都还在库里

这是这套东西比较特别的地方：**NPC 的记忆会自己长大**，而不是每次开局重置。

## 6. 面板上怎么开

`python tools/panel.py` → `http://127.0.0.1:8788`：

- 「阈值」页有 `always_reply` 开关（保存即生效，不用重启）
- 右上角切角色；每个角色可以有自己的阈值覆盖
- 「记忆」页能看/改人物卡；改完下一轮就进 prompt

---

## 7. 不建议的用法

- 拿它冒充真人做情感诈骗、刷单、引流
- 在未告知的公开群里大规模跑（平台风控 + 伦理问题）
- 把 `always_reply` 打开后接一个高活跃群还不限速（会被踢，也会烧钱）

这个项目默认的姿态是「少说、想清楚再说」。NPC 模式是把这套东西反过来用，
用之前请先想清楚你要的是「像人」还是「稳定」——两者在这套架构里是冲突的。
