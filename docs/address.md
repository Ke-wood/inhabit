# 称呼：她接受哪些叫法

> 「不许叫我大肥鱼」这件事，不该硬编码成一句 if。
> 这里只做**检测**，把「刚才被叫错了」这个事实喂给她，**具体怎么反应仍由人格决定**。

---

## 1. 规则写在文件里

`记忆/称呼.md`，纯文本，改完下一拍生效：

```markdown
## 可以这么叫我

- 鲸鲸
- 小鲸鱼

## 别这么叫我

- 大肥鱼
- 肥鱼

## 被叫错了，我怎么办

第一次纠正一下就行。第三次以后可以真生气。
```

- `##` 开头的小节，下面用 `- 名字` 列
- 含「别 / 不要 / 不许 / 讨厌 / 禁 / 错」的小节 → **禁称**
- 含「可以 / 喜欢 / 叫我」的小节 → **正名与昵称**
- 「被叫错了怎么办」那一节会被原样贴进 prompt

删掉整个文件 = 她不在意怎么被叫。

---

## 2. 优先级：禁称高于别名

这是「不许叫我大肥鱼」能生效的关键。

`config.json` 的 `identity.names` 决定「哪些词是在叫她」。
如果 `大肥鱼` 既在别名里、又在禁称里 —— **按禁称处理**。

否则会出现这种蠢事：她一边被叫大肥鱼一边应声，因为别名表里认了。

```
identity.names = ["鲸鲸", "大肥鱼"]     ← 听见都会回头
称呼.md 禁称 = ["大肥鱼"]              ← 但听见会不高兴
结果：回头，然后纠正你。
```

---

## 3. 三档语气

同一个禁称被叫的次数记在 `self_state` 里（`addr_wrong_<名字>`），递进：

| 次数 | 提示词里给她的话 |
|---|---|
| 第 1 次 | 这不是你的名字，但这是第一次。纠正一下就行，别翻脸 |
| 第 2 次 | 你已经说过一次了，他还在叫。可以明显不耐烦，但别重复上次那句 |
| 第 3 次+ | 可以真的生气 —— 短、硬、不解释。也可以干脆不接这个称呼 |

每一档都附一句 `（你叫鲸鲸，不叫「大肥鱼」。）`，
避免她被叫多了就默认自己叫那个。

**语气是建议，不是命令** —— 模型仍然可以决定这次就算了。

---

## 4. 实测

用真实模型跑一遍（`tests/test_live_llm.py`），收到「大肥鱼你在干嘛」时她的原话：

> 谁大肥鱼，我叫鲸鲸。
> 你喊错就算了，鱼可记仇。

有纠正、有记忆点、有鲸鱼自称。这是 prompt 的效果，不是写死的台词。

---

## 5. 代码在哪

| 文件 | 作用 |
|---|---|
| `core/address.py` | 读规则、检测禁称、累计次数、生成提示词 |
| `core/live.py` | 收到消息时检测并计数，挂在这条消息上 |
| `core/act.py` | `_address_block()` 把提示拼进这一拍的 prompt |

想加「叫对了有好处」，在 `core/address.py: describe()` 里加一个正向分支即可。
