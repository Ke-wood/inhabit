# 架构

> 一句话：**存在层永远在跑，心智层偶尔醒一次，行动层只在她想做点什么时启动。**
> 沉默是默认动作。

---

## 1. 三层

```
┌──────────────────────────────────────────────────────────┐
│  存在层 Heartbeat（纯本地，2 秒轮询，零 LLM）              │
│  时间流逝 · 精力 · 睡眠 · 念头强度发酵 · 在场的人           │
└──────────────────────────┬───────────────────────────────┘
                           │ 有新消息 / 念头够强 / 空闲够久
┌──────────────────────────▼───────────────────────────────┐
│  心智层 Think（1 次 LLM，短）                              │
│  产出：一条念头（内容 + 冲动 + 犹豫 + 打算怎么做）           │
│  可以是「没什么想说的」                                     │
└──────────────────────────┬───────────────────────────────┘
                           │ 冲动压过犹豫
┌──────────────────────────▼───────────────────────────────┐
│  行动层 Act（最多 3 步 LLM 工具循环）                      │
│  say / browse_bili / search_web / fetch / recall /        │
│  remember / forget / feel / revise_self / sleep / focus / │
│  resolve / drop / wait / publish_bili                     │
└──────────────────────────┬───────────────────────────────┘
                           │
                     结果回流到存在层
             （说过话 → 掉精力；看完视频 → 长出新念头）
```

对应代码：

| 层 | 文件 | 入口 |
|---|---|---|
| 存在层 | `core/live.py` | `Live.tick()` |
| 心智层 | `core/mind.py` | `think()` |
| 行动层 | `core/act.py` | `act()` |
| 记忆 | `memory/store.py` | `recall()` / `add_event()` / `add_fact()` |
| 人格 | `core/self.py` + `core/persona.py` | `Self` |

## 2. 「一拍」怎么走

一拍 = 一次 `Live.tick()`。默认 2 秒轮询一次，但不是每拍都想事。

1. **护栏**（本地）
   距上次「想」是否超过 `min_think_gap`？在思考时刻里用 `focus_gap`，空闲用 `idle_think_gap`；
   深夜静默、睡着则跳过；刚说完话受 `speak_gap` 限制。
2. **取输入**
   有新消息 → 念头种类 `reply`；悬着的事到期 → `pursue`；都没事且闲够久 → `wander`。
3. **想**（1 次 LLM）
   输入：自我认知（`我是谁.md`）+ 状态（心情/精力/在场的人）+ 最近对话
   + 悬着的事 + 少量记忆 + **上一轮想过什么、后来怎样了**。
   输出：`{"content": …, "urge": 0…1, "hesitate": 0…1, "plan": …}`。
4. **裁决**（纯算术）
   `urge < 0.2` → 不做；`urge - hesitate < -0.15` → 不做；差值落在 ±0.15 → 掷骰子 `p = urge/(urge+hesitate)`。
5. **做**（0～3 次 LLM）
   工具循环。每次动作的结果作为观察回灌给下一步，直到她说 `say` / `wait` 或步数用尽。
   用了 `search_web` / `fetch` / `browse_bili` 时，结果回来先插一次 `react()`
   —— 只冒一句心里话、不输出 JSON，再带着这句话进决策。
   把「读完一坨」和「决定做什么」拆成两次前向，否则她会跳过内容直接说、或者照抄标题。
   一次行动最多补 2 次（`_MAX_REACT`），卡的是账单。
6. **落库**
   说过的话进 `events(kind='speech')`；念头标 done 并写下 `outcome`
   （「说了什么 / 查到什么 / 没做成」）；精力扣一点；关系微调。
7. **后台整理**（另一条慢循环，`core/janitor.py`）
   每 30 分钟：从对话抽事实 → 更新好感 → 导人物卡到 `记忆/我/*.md` → 衰减旧事件。
   每天 23 点后：写日记（写给自己，不是总结报告）。

## 3. 为什么这样分

- **想 ≠ 说**。把「产生意图」和「生成文本」拆开，才有「憋着不说」这种事。
  如果一步到位生成回复，模型就没有机会决定「算了」。
- **概率门不够**。v1 用 `sigmoid` 打分决定说不说，结果是「像人但要靠调参」；
  v2 让模型自己在念头里给出冲动/犹豫，人味来自权衡而不是阈值。
- **记忆必须是资源，不是上下文**。SQLite 存全部，每拍只带「现在用得上」的；
  她可以主动 `recall`，这才叫「想起来」。
- **思考是连续的，不是每拍重启**。念头办完不是消失，而是留下 `outcome`。
  否则她每轮都在「第一次想这件事」，同一句话能反复冒出来十几次 ——
  这不是记性差，是**上一轮的结果没有回传**。
- **读和判要分开**。工具返回的内容如果直接塞进决策 prompt，模型要在一次前向里
  同时「读完」和「决定」，结果是跳过或复读。中间插一次只产出一句话的
  `react()`，让它先有自己的态度，再谈做什么。

## 4. 上下文预算（自主模式一拍）

| 块 | 大致字数 |
|---|---|
| 自我认知（`我是谁.md`）+ 反 AI 味硬规则 | 400 |
| 当前状态（心情/精力/在哪儿/在场的人） | 150 |
| 关系摘要 | 200 |
| 检索到的记忆 | 800 |
| 最近对话 | 1500 |
| 格式约束 | 100 |

超了先丢最近对话，**不丢人格和记忆**。

应答模式（v1）不走这条：它每轮固定注入最近 16 条 + 每人 N 条事实/事件 + 12 条召回，
变量在 `thresholds.recall_limit / facts_per_person / events_per_person`。

## 5. 有界性（防止「聊到停不下来」）

| 约束 | 默认 | 位置 |
|---|---|---|
| 行动步数 | 3 | `core/act.py` |
| 一次行动里看视频 | 1 | `core/act.py` |
| 一次行动里搜索 | 2 | `core/act.py` |
| 活跃念头池 | 20 条 | `memory/store.py` |
| 悬着的事 | 20 条 | `thresholds.keep_loops` |
| 单条消息长度 | ≤ 30 字（prompt 约束） | `core/persona.py` |
| 分条发送 | ≤ 3 段 | `core/brain.py: split_segments` |
| 深夜主动开口 | 关闭 | `thresholds.quiet_hours` |

## 6. v1 / v2 分叉

同一个入口 `run_wx.py`：

```
run_wx.py                 → main()     → v1：每 scene 一个 HeartFlow，概率门 + 频率闸
run_wx.py --v2            → main_v2()  → v2：一个 Live，想 → 念头 → 做
```

两套共用 `Self` / `store` / `sender`，区别只在「要不要说」的判断方式：

| | v1 | v2 |
|---|---|---|
| 决策 | `sigmoid(特征) > threshold` | 冲动 vs 犹豫 |
| 记忆 | 固定注入 | 她自己 `recall` |
| 动作 | 只会说话（+ 冲动主动开口） | 14 种 |
| 关系 | 被动累加 | 被动 + 她自己 `feel` |
| 必回 | `always_reply: true` 即可 | 不适用（沉默是设计） |

**一次只能跑一个。** 启动会占住 `8790` 端口，第二个实例自己退出。

## 7. 数据流（收 → 想 → 发）

```
平台 ──POST──▶ channels/wxhook.py:8771/cb ──归一化──▶ data/wx_inbox.jsonl
                                                          │
                                              run_wx 主循环轮询
                                                          ▼
                              Live.feed()（v2）/ HeartFlow.tick()（v1）
                                                          ▼
                                    store（events / facts / relations / thoughts）
                                                          ▼
                              channels/router.py ──按场景前缀──▶ QQ 网关 / 微信 hook / HTTP
```

收件服务只绑 `127.0.0.1`，**没有鉴权**。不要把它暴露到公网，也不要在不可信的本机环境里跑。
