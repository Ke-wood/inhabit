# 记忆模板

这个目录是**空白模板**，不包含任何人。首次运行前，把它复制成运行时目录：

```bash
python tools/init_persona.py          # 交互式生成，推荐
# 或者手工：
cp -r memory_template 记忆
```

复制后的 `记忆/` 就是她的记忆库（Obsidian 风格纯文本），已在 `.gitignore` 里，不会进版本库。

---

## 文件 ↔ 数据库的同步规则

记忆的**真身是 SQLite**（`data/feiyu.db`），`记忆/` 是它的**可读镜像**。规则只有三条：

| 方向 | 时机 | 规则 |
|---|---|---|
| 库 → 文件 | 后台整理（默认每 1800 秒） | 把 `facts` 按人导出成 `我/<人名>.md`，一行一条事实 |
| 文件 → 库 | 启动时、整理时 | 只同步**新增和修改**；文件里被删掉的行，在下次导出水位之前**不判定为遗忘** |
| 人 → 文件 | 随时 | 直接编辑即可，下一拍生效 |

事实行的格式固定，改这一行等于改这条记忆：

```markdown
- [f12] 经历：说好下周一起去爬山
```

- `f12` 是事实 id（`facts.id`），**新写的事实可以省略**，程序会当成新条目
- 分类：`经历 / 身份 / 偏好 / 关系 / 观点`
- 人物卡头部的 `<!-- wxid: ... -->` 用来把文件和人对应起来，没有就靠文件名

> 为什么会「删行不立刻遗忘」：早期版本把「文件里没有」当成「这条事实是假的」，
> 结果程序没来得及导出时，每次启动都在删记忆。现在用导出水位兜住这件事。

## 目录里每个文件是干什么的

| 文件 | 作用 | 谁在写 |
|---|---|---|
| `我是谁.md` | **L1 自我认知**，每拍重读。改这一句，她下一拍就变 | 你 + 她自己（`revise_self`） |
| `人设卡.md` | v1 的人设卡（L1 内核 + 反 AI 味硬规则）。v2 只留档，不注入 | 你 |
| `我自己的记忆.md` | 她自己的备忘，有字数上限（默认 520 字注入、1040 字落盘） | 她自己 |
| `我/<人名>.md` | 每个认识的人一张卡 | 程序导出 + 你手改 |
| `index.md` | 人物索引与计数，程序自动生成，**别手改** | 程序 |

## 换一个人

最小改动集：

1. 重写 `我是谁.md`
2. 清空 `我/`，只留 `_示例.md`
3. 删掉 `data/feiyu.db`（会重新建空库）
4. 改 `config.json` 里的 `identity.names` 与 `profiles` 的键
5. 按需调阈值

代码不用动。
