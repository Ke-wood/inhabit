# 预设

现成的人设，装完就能跑。每个预设是一份**可以整份替换的文本**，不含代码、不含图片、不含模型。

```bash
python tools/init_persona.py --preset <名字>
```

| 预设 | 是谁 | 装它做什么 |
|---|---|---|
| [`dafeiyu`](dafeiyu/README.md) | 蓝色大肥鱼（DeepSeek 鲸鱼娘），B 站 2026-10 爆火的同人形象 | 会叫你爸爸、找你要 token 吃白饭、爱顶嘴、怕被弃用 |

## 预设长什么样

```
presets/<名字>/
├── README.md          说明：她是谁、出处、边界
├── name.txt           角色名（装的时候写进 config.json）
├── aliases.txt        别名，一行一个（她听见这些词会以为在叫她）
└── persona/           会被整份复制成运行时的 记忆/
    ├── 我是谁.md          L1 自我认知，每拍重读 ★
    ├── 人设卡.md          v1 的卡（L1 内核 + 反 AI 味硬规则）
    ├── 我自己的记忆.md    她自己的备忘
    ├── index.md          人物索引（程序会重写）
    └── 我/               人物卡
        └── *.md
```

> 目录名叫 `persona/` 而不是 `记忆/`，是为了避开 `.gitignore` 里 `记忆/` 的规则。
> 装的时候会复制成 `记忆/`。

## 严格规则

预设会随仓库公开分发，所以：

| 必须 | 原因 |
|---|---|
| 标注出处 | 如果是基于他人作品/公开梗的形象，写清来自哪里 |
| 保留反 AI 味硬规则 | 这是所有预设的共同底线，别为了角色特色牺牲可读性 |
| 写明边界 | 哪些话题不接（色情、冒充真人、违法），写进人设卡 |
| 不含二进制素材 | 不塞图片、Live2D 模型、音频 —— 版权归原作者，本仓库不分发 |
| 是虚构的或公开的同人 | 不写真实的人 |

| 禁止 | 原因 |
|---|---|
| 抄具体作品的大段台词 | 只归纳特征，不复制原文 |
| 冒充官方 | 同人就是同人，人设里要承认 |
| 性化未成年形象 | 无论出发点是什么，不提供 |
| 真实个人信息 | 包括真实姓名、账号、住址 |

## 自己做一个

1. 建目录 `presets/你的名字/`
2. `name.txt` 写角色名，`aliases.txt` 写别名
3. `persona/` 下放 `我是谁.md`、`人设卡.md`（可直接抄 `memory_template/` 改名）
4. 写 `README.md`：她是谁、出处、边界
5. 跑一遍：`python tools/init_persona.py --preset 你的名字`
6. 跑测试：`python tests/test_presets.py`

测试会自动检查：文件齐不齐、有没有混进二进制素材、硬规则在不在、
装完 config 对不对、会不会静默覆盖已有记忆。

## 换成别的样子

预设装完就是普通的 `记忆/` 目录，你可以随便改：

- `记忆/我是谁.md` —— 下一拍生效
- `记忆/人设卡.md` —— 硬规则 + L1
- `记忆/我自己的记忆.md` —— 她自己的备忘

想回到空白：`python tools/init_persona.py --force`
