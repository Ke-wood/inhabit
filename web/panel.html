    教程
    
    
    
  
    
  
    
    
      
      
    1. 阈值：拖动滑块即可，下一拍就生效。运行中的角色要先去顶部点「关闭」才能改。
      2. 
      
    2. 思考模式：填分钟数点开启，她会围绕这个主题高频思考（默认 20 秒一拍），到点自动恢复。
      3. 
      
    3. 人设：就是 我是谁.md。推荐 50～200 字，用「我是…」的口吻写，改完下一轮「想」时生效。
      4. 
      
    4. 记忆：我自己的记忆.md。她 remember 时会往里写，你也可以直接改。
      5. 
      
    5. 好感度：点人名可以展开这个人的全部记忆，每条都能改或删。
      6. 
      
    6. 渠道：可以加任意多个。场景名带前缀就自动分流，比如 tg_ → Telegram 渠道。
      7. 
      
    7. 配置体检：哪项没配好会标黄或红，照着提示补。
      8. 
    
    
  
    

    


    

    
  
    大脑 / API
    
  
    
    
    
    
    
  
    
  
    留空则读环境变量 DEEPSEEK_API_KEY / OPENAI_API_KEY；任何 OpenAI 兼容端点都行。
    

    


    
  
    Bilibili（当前角色专用）
    
  
    
    
    
  
    
  
    
    需要的字段：SESSDATA bili_jct DedeUserID buvid3
    （sessdata 管登录，bili_jct 管发评论/点赞，少了它会 -111 CSRF 校验失败）
    
    取法：浏览器登录 b 站 → F12 → Application → Cookies → bilibili.com → 把这几项拼成一行。
    
    留空则读 data/secrets/bili_cookie.txt。这个 cookie 只属于当前角色，别的角色各有一份。
